📁 Meus Projetos & Tecnologias

Bem-vindo à central de projetos interativos do meu portfólio no estilo Windows 95!

🛠 Tecnologias Utilizadas

HTML5 CSS3 (Pixel Art / Win95) JavaScript (Vanilla ES6+) Canvas API iFrames Dinâmicos

🎮 O que você encontra aqui?

Navegue pelo Windows Explorer na janela de Projetos para abrir cada aplicação individualmente em uma nova janela independente com iframe. Você pode abrir várias janelas ao mesmo tempo, redimensioná-las, maximizá-las e minimizá-las para a barra de tarefas!

💡 Como incluir seus próprios projetos:
Abra o arquivo script.js e insira suas páginas web ou links no array listaProjetos. O sistema gerará automaticamente os ícones no Explorer e abrirá o iframe correspondente ao clicar!
